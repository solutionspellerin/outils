# Outils interactifs — Solutions Pellerin

Outils HTML statiques publiés sur GitHub Pages, intégrés dans le site Zoho Sites de Solutions Pellerin via iframe.

## Contenu

- `index.html` — page d'accueil listant les deux outils
- `Estimateur.html` — estimateur de coûts d'implantation BI
- `Architecture.html` — visualisation de l'architecture de la solution
- `soltutions-pellerin.png` — logo Solutions Pellerin
- `agendrix-marque-logo-signature-greenery.png` — logo Agendrix

## URLs publiques (après activation de GitHub Pages)

- Accueil : `https://solutionspellerin.github.io/outils/`
- Estimateur : `https://solutionspellerin.github.io/outils/Estimateur.html`
- Architecture : `https://solutionspellerin.github.io/outils/Architecture.html`

## Mise à jour

Pour modifier un outil : éditer le fichier HTML correspondant, puis pousser sur la branche `main`. GitHub Pages republie automatiquement (~30 secondes).
